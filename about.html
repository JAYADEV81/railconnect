OUR STORY

A little less planning.
A lot more exploring.

RailConnect is a student-built demonstration of a railway reservation portal.

THE IDEA

Technology should make the first step feel easy.

This project demonstrates how a responsive front end can connect to a Python Flask backend and a SQLite database to save and retrieve reservation records.

It includes train search, passenger forms, fare estimates, booking references, and a simple admin dashboard for classroom demonstration.
